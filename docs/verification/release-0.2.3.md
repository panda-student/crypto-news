# 0.2.3 设置页原型对齐验收

本版修复 0.2.2 设置页与 `docs/prototypes/feed-first-v17.html` 的布局和样式不一致。此前实际页面仍使用旧版独立设置布局，功能验证没有覆盖这项视觉差异。

## 界面与行为

- 首页打开设置使用居中弹窗，关闭后保留原消息流和未发送的追问。直接访问 `/settings` 复用同一份面板。
- 采用原型的左侧导航、浅灰绿配色、卡片、间距和控件样式。模型、推送、插件等实际管理入口保留在“更多设置”下。
- X 账号独立区域，支持搜索、添加、暂停、删除和打开 X；账号列表限制高度，溢出时显示向下滚动提示。RSS 长标题和地址在卡片内截断，可通过 title 查看完整内容。
- 关注币种显示已保存列表，支持添加、移除、撤销、保存。保存期间禁止并发编辑；状态同步不会覆盖用户未保存的输入。
- 网络、系统、AI 与 MCP 使用相同设计；MCP 配置操作仍先预览并确认。
- 设置内容按分类加载，HTTP 错误显示重试入口；配置更新和重新打开弹窗后刷新已加载内容，保留未保存表单。

## 验证证据

[原型、旧版和修复版截图对照](settings-0.2.3.html)。截图来自独立验收数据目录，没有更改用户当前配置，也没有调用真实模型或发送渠道消息。

| 检查 | 结果 |
| --- | --- |
| 1440 × 1000 弹窗 | x=180、y=105、宽1080、高790，与原型一致 |
| 1200 × 800、390 × 844 | 可用；窄屏面板无水平溢出 |
| 八个设置分类 | 实际点击加载并切换，无浏览器脚本错误 |
| 关注币种 | 添加 DOGE、保存、移除、撤销；延迟保存和同步竞态验证通过 |
| X 账号 | 搜索、添加、内部滚动、暂停、确认删除；溢出箭头可见 |
| 加载失败 | 注入一次 HTTP 503，点击重试成功恢复 |
| MCP 与页面同步 | 通过真实操作计划预览确认新增测试信源，返回信源页可见新配置 |
| 首页状态保留 | 关闭设置后未发送追问保留 |
| 工作区测试 | release 模式 476 通过、1 忽略 |
| 静态检查 | cargo fmt、release Clippy 全工作区 all-targets -D warnings 通过 |
| 签名 | 安装包签名有效，篡改后的安装包被拒绝 |

界面最终复核使用本次打包的 `target/release/desktop.exe serve` 启动其内嵌应用，通过浏览器操作。独立验收环境没有桌面窗口能力，因此系统开关按实际能力禁用；这不等同于覆盖安装后的原生窗口验收。本次没有执行真实覆盖安装或安装更新，用户此前选择稍后进行升级安装验证。
