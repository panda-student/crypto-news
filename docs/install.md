# 消息面分析：安装与使用

## 安装或更新

1. 从根目录 `release/` 运行 `CryptoNews_0.2.2_x64-setup.exe`。
2. 可直接覆盖安装。安装器先请求当前安装目录的应用正常退出；旧版缩到托盘不退出时，等待 4 秒后仅结束该安装目录的进程，不再无限等待。
3. 默认安装目录是 `D:\CryptoNews`（没有 D 盘时为 `C:\CryptoNews`），可在安装向导修改。
4. 安装完成后重新启动，首页应显示“消息雷达”、紧急事件/重要利空/重要利好三个概览和自动刷新倒计时。

安装包带 Tauri 更新签名（用于应用校验更新），尚无 Windows Authenticode 代码签名。缺少 WebView2 时安装程序需要联网下载组件。若出现 NSIS 无法写入临时文件，请使用 `release/` 的导出包；发布脚本会修正开发工作区继承的低完整性标记。

## 首次配置

进入 **设置 → 模型**，填写服务地址、模型名称和 API 密钥，并测试连接。模型配置默认值以界面为准。

进入 **设置 → 信源**，管理采集来源、周期；X 来源可在此登录。进入 **设置 → 推送**，配置企业微信或绑定微信，并按需要测试发送。

进入 **设置 → 网络** 配置代理；进入 **设置 → 系统** 配置开机自启、关闭窗口行为以及更新。外部请求使用配置的代理；选择直连后按直连配置请求。

## 消息与追问

- 顶部重点速览按原始发布时间展示：紧急事件最近 6 小时，重要利空/利好最近 24 小时；按事件聚合并展示核实状态。下方时间流可继续加载更早消息。
- 每 30 秒刷新已采集消息，也可点击“一键刷新消息”；来源抓取仍按各自采集周期运行。
- 点击消息加入当前会话，最多 20 条。底部展示全部参考消息，可逐条移出或撤销移出。
- 底部追问参考当前全部消息，卡片快捷追问仅参考该条；回答流式展示并可停止，引用可打开原文。
- 会话和参考消息会保存。移出消息不删除历史回答及当时引用。

## 数据位置

配置和数据库位于 `%APPDATA%\crypto-news`。更新安装包不会清除这里的数据。卸载通过 Windows 设置 → 应用进行，用户数据目录默认保留。

## 从源码打包

根目录运行 `./package.ps1`，编译并输出到 `release/`。不要用 `-StageExisting` 代替修改代码后的重新构建。

发行文件包括安装包、SHA-256、更新签名 `.sig` 和 `latest.json`。首次打包须自行生成 Tauri 签名密钥并保存在仓库外，通过 `TAURI_SIGNING_PRIVATE_KEY` 提供；同时更新 `tauri.conf.json` 的公钥。克隆者应使用自己的仓库、更新地址与签名密钥。

## 自动更新与 MCP

**系统 → 自动检查更新** 默认开启，启动后及每 6 小时检查 GitHub Release。发现版本后，由用户确认下载安装；校验签名通过才会停止核心服务和启动安装器。可随时手动检查。

**AI 与 MCP** 页面提供当前可执行文件的 MCP 客户端配置。先启动桌面应用，再用该配置连接。查询直接返回；变更生成待确认卡片，在应用确认后执行。API 密钥只在本机确认输入框提交。内部 AI 使用相同工具，普通消息分析保持原有流程。
